# BTS Key 사용 절차

1. **사전 조건**: iMac과 MacBook을 시스템 설정 → Bluetooth에서 한 번 페어링해 둔다(관리자 불필요). KeyPad가 실행 중이면 종료한다(같은 링크에 HID 레코드를 하나 더 올리므로 충돌).
2. 설치: DMG에서 앱을 응용 프로그램으로 끌어 놓고 실행한다(개발 중이면 `./scripts/build-app.sh && open build/BTSKey.app`). 첫 실행에 나오는 안내 창이 권한·페어링·연결을 순서대로 이끈다. 안내는 메뉴 → 도움말 → **사용 방법 보기…**로 다시 볼 수 있다.
3. 권한: 안내 창의 "허용하기…" 또는 메뉴 → 도움말 → **권한 확인…**. ad-hoc 서명 빌드는 **빌드할 때마다 다시 허용**해야 한다.
4. 기기 선택: 메뉴 위쪽 기기 목록에서 iMac 이름을 누른다. 연결한 적 있는 기기가 아이콘과 이름으로 나열되고, 연결된 기기에는 체크와 "연결됨"이 표시된다. 처음 쓰는 iMac은 **다른 페어링된 기기** 아래에 있다.
5. 메뉴 → **iMac에 연결** (기기 이름을 누르면 바로 연결된다). 아이콘이 외곽선(연결됨·입력 MacBook)으로 바뀌고 HUD에 "iMac 연결됨"이 뜬다. iMac 시스템 설정 → Bluetooth에 "BTS Key"가 키보드/마우스로 보인다.
6. **⌥⌘K**로 입력을 iMac으로 보낸다(아이콘이 주황색으로 채워지고 HUD "→ iMac"). 같은 키로 MacBook으로 돌아온다. 화면 잠금·잠자기·앱 종료·링크 끊김 시 자동으로 MacBook 입력으로 복귀한다.
7. 트랙패드가 느리면 메뉴 → **포인터 배율**을 올린다(기본 1.5×, 최대 4×). iMac 쪽 마우스 이동 속도도 함께 조정한다.

연결 방법 (둘 중 하나):
- **iMac에서**: iMac의 시스템 설정 → Bluetooth → "BTS Key" 옆 **연결**. 처음 보는 iMac이면 먼저 페어링한다. 앱은 페어링된 iMac의 연결을 받고 그 iMac을 대상으로 기억한다.
- **MacBook에서**: 앱 메뉴 → 대상 iMac 선택 → iMac에 연결.
- MacBook의 시스템 설정에서 iMac 항목의 "연결"은 쓰지 않는다. iMac은 MacBook에 제공할 프로필이 없어 스피너만 돈다.

연결 동작:
- iMac 쪽에서 연결을 시작하면(잠자기 복귀, iMac 설정의 "연결") iMac 화면에는 "연결됨"이 잠깐 떴다가 사라지고, 약 25초 뒤 앱이 스스로 연결한다. iMac이 직접 연 채널은 macOS가 앱에 넘기지 않아 쓸 수 없으므로 항상 MacBook 쪽에서 연다. 앱 메뉴에서 "연결 해제"를 누른 동안에는 반응하지 않는다.
- 끊기면 4초 뒤 한 번 다시 시도하고, 실패하면 멈춘다. iMac이 연결을 해제한 경우에는 다시 시도하지 않는다. MacBook이 잠자기에서 깨면 한 번 연결한다.
- 마지막에 연결 상태로 앱을 끄면 다음 실행 때 자동으로 연결한다.
- iMac 입력 중 링크가 끊겼다가(iMac 잠자기 등) 30분 안에 다시 붙으면 자동으로 iMac 입력으로 돌아간다(메뉴 → 재연결 시 iMac 입력 자동 복귀). iMac 로그인 화면에서 바로 암호를 칠 수 있다.
- 새로 빌드한 직후에는 블루투스 권한 창에 먼저 응답한다. 응답 전에는 앱이 HID 서비스를 등록하지 못하며, 그 사이 iMac이 연결하면 MacBook이 iMac을 입력 장치로 잡아 "연결됨"으로 보이지만 앱과는 무관하다. 앱은 등록될 때까지 1초마다 재시도한다.

로그: `/usr/bin/log stream --level info --predicate 'subsystem == "btskey"' --style compact`

iMac 입력 모드:
- **⌥⌘K**로 iMac 입력과 MacBook 입력을 오간다.
- iMac 입력 중에는 메뉴바 아이콘 아래에 주황색 테두리 상자("iMac 입력 중")가 계속 떠 있고, MacBook 포인터는 제자리에 고정·숨김된다.
- **Caps Lock으로 iMac의 한/영 바꾸기**: iMac에서 한 번 설정한다. MacBook이 iMac에 연결된 상태에서 한다.
  1. iMac의 시스템 설정 → 키보드 → 키보드 단축키… → **보조 키**
  2. 맨 위 **키보드 선택** 단추를 눌러 이 MacBook의 이름을 고른다. 눌러야 펼쳐지는 단추라서 목록처럼 보이지 않는다.
  3. **Caps Lock 키**를 **🌐 fn 기능**으로 바꾸고 완료를 누른다.
  4. iMac의 "🌐 키를 누를 때"가 "입력 소스 변경"이어야 한다.
  - 보조 키 설정은 키보드마다 따로 저장된다. iMac의 다른 키보드에 해 둔 설정은 MacBook에 적용되지 않는다.
  - iMac의 설정이 초기화되면 다시 한다. 같은 안내가 **사용 방법 보기**의 "Caps Lock으로 한/영" 쪽에 있고, 메뉴 → 설정 → Caps Lock → iMac → **한/영 전환 설정 방법…**을 누르면 그 쪽이 바로 열린다.
- 메뉴 → **Caps Lock → iMac**에서 Caps Lock을 어떻게 보낼지 고른다. 선택은 iMac마다 따로 기억된다(메뉴 첫 줄에 적용 대상이 보인다). 실제 누름/뗌 시점 그대로 전달한다.
  - **Caps Lock 그대로 (기본, 권장)**: 위 설정과 함께 쓴다.
  - **🌐 키로 바꿔 보내기**: MacBook을 Apple 키보드로 인식하는 iMac에서만 동작한다. 시험한 iMac(macOS 15.7.4)은 그렇게 인식하지 않았다.
  - **⌃스페이스로 바꿔 보내기**: iMac의 "이전 입력 소스 선택" 단축키가 기본값 그대로일 때 동작한다.
- MacBook의 한/영도 함께 바뀌는 것은 정상이다. macOS가 Caps Lock을 앱보다 먼저 처리하기 때문이며, iMac 입력을 마치면 앱이 MacBook의 입력 소스를 원래대로 되돌린다.
- MacBook의 🌐(fn) 키는 🌐 바이트로 전달된다. iMac이 MacBook을 Apple 키보드로 인식할 때만 동작한다.
- 메뉴 → **iMac 입력 중 절전**: 끔 / 화면 어둡게(밝기 10%, 기본) / 화면 끄기(밝기 0). MacBook 입력으로 돌아오면 원래 밝기로 복원한다. 앱이 비정상 종료돼도 다음 실행 때 복원한다.

메뉴 구성:
- 기기 목록: 연결한 적 있는 컴퓨터(최근 8대). 오른쪽 하위 메뉴에서 연결 또는 목록에서 제거. "다른 페어링된 기기"에 아직 연결한 적 없는 페어링 컴퓨터와 Bluetooth 설정 열기.
- 설정: 포인터 배율, iMac 입력 중 절전, Caps Lock → iMac, 재연결 시 자동 복귀, 로그인 시 자동 실행.
- 도움말: 사용 방법 보기(첫 실행 안내 다시 열기), 권한 확인, 문제 해결 안내, 진단 로그 내보내기(데스크탑에 텍스트 파일), 지원 웹사이트, 문의하기.
- BTS Key 정보: 버전과 지원 연락처.

## 다른 iMac으로 옮기기 (표준 절차)

1. **MacBook의 시스템 설정 → Bluetooth 화면을 열어 둔다.** MacBook은 이 화면이 열려 있는 동안에만 검색된다. 그 상태에서 새 iMac의 시스템 설정 → Bluetooth에서 이 MacBook 옆 "연결"을 눌러 페어링한다. (이전 iMac과의 페어링은 지워도 되고 두어도 된다.)
2. MacBook 앱은 5초 안에 새 페어링을 감지한다. 그때 연결이 없으면 새 iMac을 대상으로 삼아 바로 연결하고 HUD에 "〈이름〉 페어링됨 · 연결 중"을 띄운다. 이전 iMac에 아직 연결돼 있었다면 목록에만 추가하고 알린다. 그 경우 메뉴 → 기기 목록에서 새 iMac 이름을 누르면 옮겨 간다.
3. 이전 iMac의 페어링을 지우면 앱은 즉시 그 iMac에 대한 재시도를 멈추고 대상에서 지운다.
4. 앱이 꺼져 있는 동안 페어링한 iMac도 다음 실행 때 새 기기로 감지해 연결한다. 앱을 처음 쓰기 전부터 페어링돼 있던 컴퓨터는 자동으로 고르지 않으며, 메뉴 → 다른 페어링된 기기에서 선택한다. 한 번도 연결한 적 없는 Mac은 macOS가 아직 이름을 모르므로 "Mac (aa:01)"처럼 주소 끝자리로 표시되고, 처음 연결되면 실제 이름으로 바뀐다.

## 자동 재시도와 명시적 재시도

- 링크가 끊기면 4초 뒤 **한 번만** 자동으로 다시 시도한다. 실패하면 HUD와 상태 줄에 안내가 뜨고 메뉴에 **지금 다시 연결**이 나타난다.
- iMac의 Bluetooth 설정에서 "연결 해제"를 누른 경우에는 자동으로 다시 연결하지 않는다.
- iMac이 먼저 연결을 시도하면(잠자기 복귀, iMac 설정의 "연결") 앱이 약 25초 뒤 한 번 연결한다. iMac의 시도는 그 링크가 끊어진 뒤에야 앱에 보이기 때문이다. 더 빨리 쓰려면 MacBook 메뉴의 **지금 다시 연결**을 누른다(4~5초). 앱의 시도가 실패하면 같은 신호로는 다시 연결하지 않는다.
- 기기 목록에서 이름 클릭, '〈이름〉'에 연결, 지금 다시 연결은 자동 시도 횟수를 처음으로 되돌린다.
- 메뉴 상태 줄의 "블루투스: 링크 연결됨 · 키보드 채널 없음"은 시스템 설정에는 "연결됨"으로 보이지만 키보드로는 아직 쓸 수 없는 상태다. 자세한 내용은 `docs/bluetooth-link-model.md`.

## 화면 표시 (HUD)

- 연결 중에는 회전 표시가 결과가 나올 때까지 떠 있다.
- 그 밖의 표시는 배지 둘레의 게이지가 줄어들어 0이 되면 사라진다: 입력 전환 4초, 연결됨 6초, 연결 끊김 9초.
- 우상단 X를 누르면 바로 사라진다. iMac 입력 중에는 포인터가 iMac에 있어 누를 수 없다.
