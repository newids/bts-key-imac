# BTS Key 사용 절차

1. **사전 조건**: iMac과 MacBook을 시스템 설정 → Bluetooth에서 한 번 페어링해 둔다(관리자 불필요). KeyPad가 실행 중이면 종료한다(같은 링크에 HID 레코드를 하나 더 올리므로 충돌).
2. 설치: DMG에서 앱을 응용 프로그램으로 끌어 놓고 실행한다(개발 중이면 `./scripts/build-app.sh && open build/BTSKey.app`). 첫 실행에 나오는 안내 창이 권한·페어링·연결을 순서대로 이끈다. 안내는 메뉴 → 도움말 → **사용 방법 보기…**로 다시 볼 수 있다.
3. 권한: 안내 창의 "허용하기…" 또는 메뉴 → 도움말 → **권한 확인…**. ad-hoc 서명 빌드는 **빌드할 때마다 다시 허용**해야 한다.
4. 기기 선택: 메뉴 위쪽 기기 목록에서 iMac 이름을 누른다. 연결한 적 있는 기기가 아이콘과 이름으로 나열되고, 연결된 기기에는 체크와 "연결됨"이 표시된다. 처음 쓰는 iMac은 **다른 페어링된 기기** 아래에 있다.
5. 메뉴 → **iMac에 연결** (기기 이름을 누르면 바로 연결된다). 아이콘이 외곽선(연결됨·입력 MacBook)으로 바뀌고 HUD에 "iMac 연결됨"이 뜬다. iMac 시스템 설정 → Bluetooth에 "BTS Key"가 키보드/마우스로 보인다.
6. **⌥⌘K**로 입력을 iMac으로 보낸다(아이콘이 주황색으로 채워지고 HUD "→ iMac"). 같은 키로 MacBook으로 돌아온다. 화면 잠금·잠자기·앱 종료·링크 끊김 시 자동으로 MacBook 입력으로 복귀한다.
7. 트랙패드가 느리면 메뉴 → **포인터 배율**을 올린다(기본 1.5×, 최대 4×). iMac 쪽 마우스 이동 속도도 함께 조정한다.

연결 방법 (둘 중 하나):
- **iMac에서**: iMac의 시스템 설정 → Bluetooth → "BTS Key" 옆 **연결**. 처음 보는 iMac이면 먼저 페어링한다. 앱은 페어링된 iMac의 연결을 받고 그 iMac을 대상으로 기억한다.
- **MacBook에서**: 앱 메뉴 → 대상 iMac 선택 → iMac에 연결.
- MacBook의 시스템 설정에서 iMac 항목의 "연결"은 쓰지 않는다. iMac은 MacBook에 제공할 프로필이 없어 스피너만 돈다.

연결 동작:
- iMac 쪽에서 연결을 시작하면(잠자기 복귀, iMac 설정의 "연결") 앱이 그 링크를 감지해 4초쯤 뒤에 스스로 연결한다. iMac이 직접 연 채널은 macOS 프레임워크가 앱에 데이터를 넘기지 않아 쓸 수 없으므로 항상 MacBook 쪽에서 연다. 앱 메뉴에서 "연결 해제"를 누른 동안에는 반응하지 않는다. iMac이 잠자기에서 깨어나거나 iMac의 블루투스 설정에서 "BTS Key"를 눌러도 연결된다.
- 끊기면 2·4·8·16·30초 간격으로 다시 시도하고, 메뉴에 남은 시간이 보인다. MacBook이 잠자기에서 깨면 바로 다시 시도한다.
- 마지막에 연결 상태로 앱을 끄면 다음 실행 때 자동으로 연결한다.
- iMac 입력 중 링크가 끊겼다가(iMac 잠자기 등) 30분 안에 다시 붙으면 자동으로 iMac 입력으로 돌아간다(메뉴 → 재연결 시 iMac 입력 자동 복귀). iMac 로그인 화면에서 바로 암호를 칠 수 있다.
- 새로 빌드한 직후에는 블루투스 권한 창에 먼저 응답한다. 응답 전에는 앱이 HID 서비스를 등록하지 못하며, 그 사이 iMac이 연결하면 MacBook이 iMac을 입력 장치로 잡아 "연결됨"으로 보이지만 앱과는 무관하다. 앱은 등록될 때까지 1초마다 재시도한다.

로그: `/usr/bin/log stream --level info --predicate 'subsystem == "btskey"' --style compact`

iMac 입력 모드:
- **⌥⌘K**로 iMac 입력과 MacBook 입력을 오간다.
- iMac 입력 중에는 메뉴바 아이콘 아래에 주황색 테두리 상자("iMac 입력 중")가 계속 떠 있고, MacBook 포인터는 제자리에 고정·숨김된다.
- Caps Lock은 메뉴 → **Caps Lock → iMac**에서 고른 키로 바뀌어 전달된다(실제 누름/뗌 시점 그대로). MacBook 쪽 입력 소스는 iMac 입력을 마칠 때 원래대로 되돌린다.
  - **🌐 키 (기본)**: iMac의 "🌐 키를 눌러 입력 소스 변경" 설정으로 한/영이 바뀐다. iMac의 키보드별 "Caps Lock → 🌐" 설정이 필요 없다. 🌐 키 지원은 가상 키보드 구조를 바꾼 것이라, iMac이 이전 구조를 기억하고 있으면 iMac의 블루투스 설정에서 이 MacBook을 한 번 삭제하고 다시 페어링해야 한다.
  - **⌃스페이스**: iMac의 "이전 입력 소스 선택"(시스템 설정 → 키보드 → 키보드 단축키 → 입력 소스) 단축키를 보낸다. 재페어링 없이 동작한다.
  - **Caps Lock 그대로**: 대문자 고정으로 쓴다.
- MacBook의 🌐(fn) 키도 iMac의 🌐 키로 전달된다.
- 메뉴 → **iMac 입력 중 절전**: 끔 / 화면 어둡게(밝기 10%, 기본) / 화면 끄기(밝기 0). MacBook 입력으로 돌아오면 원래 밝기로 복원한다. 앱이 비정상 종료돼도 다음 실행 때 복원한다.

메뉴 구성:
- 기기 목록: 연결한 적 있는 컴퓨터(최근 8대). 오른쪽 하위 메뉴에서 연결 또는 목록에서 제거. "다른 페어링된 기기"에 아직 연결한 적 없는 페어링 컴퓨터와 Bluetooth 설정 열기.
- 설정: 포인터 배율, iMac 입력 중 절전, Caps Lock → iMac, 재연결 시 자동 복귀, 로그인 시 자동 실행.
- 도움말: 사용 방법 보기(첫 실행 안내 다시 열기), 권한 확인, 문제 해결 안내, 진단 로그 내보내기(데스크탑에 텍스트 파일), 지원 웹사이트, 문의하기.
- BTS Key 정보: 버전과 지원 연락처.

## 다른 iMac으로 옮기기 (표준 절차)

1. 새 iMac의 시스템 설정 → Bluetooth에서 이 MacBook을 페어링한다. (이전 iMac과의 페어링은 지워도 되고 두어도 된다.)
2. MacBook 앱은 5초 안에 새 페어링을 감지한다. 그때 연결이 없으면 새 iMac을 대상으로 삼아 바로 연결하고 HUD에 "〈이름〉 페어링됨 · 연결 중"을 띄운다. 이전 iMac에 아직 연결돼 있었다면 목록에만 추가하고 알린다. 그 경우 메뉴 → 기기 목록에서 새 iMac 이름을 누르면 옮겨 간다.
3. 이전 iMac의 페어링을 지우면 앱은 즉시 그 iMac에 대한 재시도를 멈추고 대상에서 지운다.
4. 앱을 켜기 전에 이미 페어링해 둔 iMac은 자동으로 고르지 않는다. 메뉴 → 다른 페어링된 기기에서 선택한다. 한 번도 연결한 적 없는 Mac은 macOS가 아직 이름을 모르므로 "Mac (7c:99)"처럼 주소 끝자리로 표시되고, 처음 연결되면 실제 이름으로 바뀐다.

## 자동 재시도와 명시적 재시도

- 링크가 끊기면 4초, 8초, 10초 뒤 세 번만 자동으로 다시 시도한다(약 22초). 세 번 모두 실패하면 상태줄에 "자동 재시도를 멈췄습니다"가 뜨고 메뉴에 **지금 다시 연결**이 나타난다. 그 뒤로는 iMac이 먼저 걸어오는 연결과 사용자의 명시적 조작만 받는다.
- MacBook 잠자기 복귀, 기기 목록에서 이름 클릭, '〈이름〉'에 연결, 지금 다시 연결은 모두 예산을 초기화한다.
