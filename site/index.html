MacBook을
iMac의 블루투스 키보드로.

iMac에는 아무것도 설치하지 않습니다. 블루투스 페어링 한 번이면 MacBook의 키보드와 트랙패드를 iMac에서 그대로 씁니다. 관리자 권한이 없는 관리형 iMac에서도 됩니다.

소개

키보드 하나로 두 대를 씁니다

MacBook을 그대로 iMac 앞에 놓고 쓰는 상황을 위해 만들었습니다. 키·트랙패드를 iMac으로 보내고, 단축키 하나로 돌아오고, 자리를 옮겨도 다시 붙습니다.

⌨

키보드 전달

MacBook에서 치는 모든 키가 iMac으로 갑니다. Caps Lock은 iMac의 🌐(입력 소스 전환) 키로 바뀌어 한/영 전환이 되고, ⌃스페이스나 Caps Lock 그대로로 바꿀 수도 있습니다.

☝

트랙패드 전달

이동·클릭·두 손가락 스크롤을 iMac의 마우스로 전달합니다. 포인터 배율은 1×~4×. iMac 입력 중에는 MacBook 포인터가 제자리에 숨겨져 두 화면에서 동시에 움직이지 않습니다.

⇄

한 번에 전환

⌥⌘K로 MacBook ↔ iMac 입력을 오갑니다. iMac 입력 중에는 메뉴바 아래 주황색 상자가 떠 있어 지금 어디에 치고 있는지 헷갈리지 않습니다.

☾

잠자기 뒤에도

iMac이 깨어나면 다시 붙고, 쓰던 중이었다면 iMac 입력으로 자동 복귀합니다. 로그인 화면에서 바로 암호를 칠 수 있습니다.

◐

절전

iMac 입력 중에는 MacBook 화면을 어둡게 하거나 끕니다. 돌아오면 원래 밝기로 복원합니다.

▤

기기 목록

연결한 적 있는 iMac이 메뉴에 아이콘과 이름으로 남습니다. 자리를 옮겨 다른 iMac에서 연결해 오면 그 iMac을 새 대상으로 기억합니다.

🔒

iMac에는 설치 없음

iMac 쪽에는 프로그램도, 관리자 권한도 필요 없습니다. iMac은 BTS Key를 평범한 블루투스 키보드·마우스로 봅니다.

설치

내려받아 끌어 놓으면 끝

요구 사항: macOS 13 Ventura 이상(Apple 실리콘·Intel), 블루투스. iMac 쪽은 블루투스만 있으면 어느 macOS든 됩니다.

DMG 내려받기

위의 macOS용 다운로드 버튼을 누르면 최신 버전 BTSKey-<버전>.dmg를 받습니다. 첨부된 .sha256으로 무결성을 확인할 수 있습니다.

Applications로 끌어 놓기

DMG를 열고 BTS Key 아이콘을 Applications 폴더로 끌어 놓습니다.

처음 한 번, control-클릭으로 열기

응용 프로그램에서 BTS Key를 control-클릭(오른쪽 클릭) → 열기 → 열기. Apple 개발자 인증서로 서명·공증되지 않은 앱이라 첫 실행 때만 이 절차가 필요합니다.

첫 실행 안내 따라가기

앱이 안내 창을 띄웁니다. Bluetooth·손쉬운 사용·입력 모니터링 권한을 허용하고 iMac과 페어링하면 준비가 끝납니다. 안내는 메뉴 → 도움말 → 사용 방법 보기로 언제든 다시 볼 수 있습니다.

"확인되지 않은 개발자" 경고가 뜨면 그냥 닫지 말고 control-클릭 → 열기를 쓰거나, 시스템 설정 → 개인정보 보호 및 보안 아래쪽의 그래도 열기를 누르세요.

사용 방법

페어링 한 번, 그다음은 단축키

세 단계면 됩니다. 페어링은 처음 한 번, 연결은 iMac이나 MacBook 어느 쪽에서든, 전환은 ⌥⌘K.

페어링 (처음 한 번)

iMac의 시스템 설정 → Bluetooth에서 이 MacBook을 페어링합니다. 양쪽에 같은 숫자가 보이면 승인합니다. 관리자 권한은 필요 없습니다.

연결

iMac의 Bluetooth 설정에서 BTS Key 옆 연결을 누르거나, MacBook 메뉴바의 키보드 아이콘 → iMac 이름을 누릅니다. 연결되면 아이콘이 외곽선 키보드로 바뀝니다.

전환

⌥⌘K로 iMac 입력으로 넘어가고, 같은 키로 돌아옵니다. 화면 잠금·잠자기·연결 끊김 때는 자동으로 MacBook 입력으로 돌아오므로 MacBook을 조작하지 못하는 일이 없습니다.

메뉴 구성

  • 기기 목록 — 연결한 적 있는 컴퓨터(최근 8대). 이름을 누르면 바로 연결. "다른 페어링된 기기"에 아직 연결한 적 없는 컴퓨터.
  • 설정 — 포인터 배율, iMac 입력 중 절전, Caps Lock → iMac, 재연결 시 자동 복귀, 로그인 시 자동 실행.
  • 도움말 — 사용 방법 보기, 권한 확인, 문제 해결 안내, 진단 로그 내보내기, 지원 웹사이트, 문의하기.
  • BTS Key 정보 — 버전과 지원 연락처.

한/영 전환

  • 🌐 키 (기본) — Caps Lock을 누르는 동안 iMac에 🌐가 눌린 것으로 보냅니다. iMac의 "🌐 키로 입력 소스 변경" 설정으로 한/영이 바뀝니다.
  • ⌃스페이스 — iMac의 "이전 입력 소스 선택" 단축키를 보냅니다. 재페어링 없이 동작합니다.
  • Caps Lock 그대로 — 대문자 고정으로 씁니다.

동작 원리

진짜 블루투스 키보드인 척합니다

MacBook이 Bluetooth Classic HID 장치(키보드+마우스 조합)를 흉내 냅니다. 소프트웨어 KVM과 달리 네트워크도, iMac 쪽 프로그램도 필요 없습니다.

1

서비스 게시

IOBluetooth로 HID 서비스 레코드(SDP)를 게시합니다. 그러면 iMac이 페어링된 키보드에 하듯 L2CAP 제어·인터럽트 채널을 열어 옵니다. MacBook에서 먼저 열 수도 있습니다.

2

입력 가로채기

iMac 입력 모드에서는 CGEvent 탭이 키·트랙패드 이벤트를 가로채 USB HID 리포트로 바꿉니다. 탭은 전용 스레드에서 돌아, 블루투스 쪽이 멈춰도 MacBook 입력은 멈추지 않습니다.

3

리포트 전송

리포트는 인터럽트 채널로 8ms 단위로 보냅니다. 마우스 델타는 16비트라 빠른 스와이프도 뭉개지지 않습니다.

왜 이 설계인지, 무엇을 시험했는지는 분석·설계 문서와 연결 과정 감사 기록에 있습니다.

Windows 개발 계획

같은 규격, 다른 전송 계층

Windows용은 분석까지 마쳤고 개발은 시작하지 않았습니다. 결론은 "프로토콜·로직은 단일 소스, 전송·입력 캡처·UI는 OS별 구현"입니다. 전체의 절반쯤을 공유할 수 있습니다.

계층macOSWindows공유
리포트 규격·인코딩·키코드·상태 머신순수 Swift순수 로직가능
블루투스 전송Classic HID (IOBluetooth)BLE HID over GATT (WinRT GattServiceProvider)인터페이스만

Windows 인박스 블루투스 스택에는 Classic HID 장치 역할 API가 없습니다. 양쪽에서 공개 API로 동작하는 것은 BLE HID over GATT뿐이며, Windows 쪽 어댑터가 주변장치(peripheral) 역할을 지원해야 합니다. 저가 USB 어댑터 다수가 지원하지 않습니다.

완료

0. 타당성 분석

Windows에서 BLE HID 키보드를 흉내 내는 오픈소스(windows-ble-hid, MIT)가 macOS 호스트에 자동 재연결까지 확인됨. 스택 선택지 비교 완료.

계획

1. BLE 전송을 Mac에서 먼저

macOS의 2안(CoreBluetooth, 128비트 HID UUID)으로 BLE HID over GATT 전송을 구현해 iMac에서 검증한다. Windows와 같은 프로토콜을 Mac에서 먼저 굳힌다.

계획

2. 코어 이식

HIDCore(리포트 규격·인코딩·키코드 테이블·상태 머신, 순수 Swift 약 2천 줄)를 Swift on Windows로 그대로 빌드하거나 C#으로 포팅한다.

계획

3. Windows 전송·캡처·트레이

WinRT GattServiceProvider 전송, 저수준 키보드·마우스 훅, 트레이 UI. 어댑터 진단(주변장치 역할 지원 여부)을 첫 실행 안내에 포함.

계획

4. 검증 매트릭스

Windows 10 2004+·11, Intel/Realtek/ASUS 어댑터, 대상 macOS 13~26. 재연결·잠자기 복귀·한/영 전환.

문제 해결 · 지원

막히면 진단 로그부터

메뉴 → 도움말 → 진단 로그 내보내기가 데스크탑에 텍스트 파일을 만듭니다. 그 파일을 첨부해 이슈를 남겨 주세요.

양쪽 Bluetooth 설정은 "연결됨"인데 앱은 연결 끊김을 반복해요

앱이 HID 서비스를 등록하기 전에 iMac이 연결해 오면 macOS가 그 연결을 대신 받습니다. 앱의 Bluetooth 권한 창에 먼저 응답하고, 메뉴에서 iMac 이름을 눌러 다시 연결하세요. 앱은 등록될 때까지 1초마다 재시도합니다.

Caps Lock으로 한/영이 안 바뀌어요

iMac의 시스템 설정 → 키보드에 "🌐 키를 눌러 입력 소스 변경"이 켜져 있어야 합니다. 안 되면 메뉴 → 설정 → Caps Lock → iMac에서 ⌃스페이스를 고르세요. 이 경우 iMac의 키보드 단축키 → 입력 소스에서 "이전 입력 소스 선택"이 켜져 있어야 합니다.

다른 iMac으로 옮기려면요?

새 iMac의 Bluetooth 설정에서 이 MacBook을 페어링하기만 하면 됩니다. 앱이 5초 안에 감지해 연결이 없을 때는 새 iMac에 바로 연결하고, 이전 iMac에 연결돼 있었다면 목록에 추가합니다. 이전 iMac의 페어링을 지우면 그쪽 재시도는 즉시 멈춥니다.

iMac 쪽에서 "연결"을 눌렀는데 몇 초 뒤에야 붙어요

정상입니다. iMac이 직접 연 채널은 macOS 프레임워크가 앱에 데이터를 넘기지 않아 쓸 수 없어서, 앱은 iMac이 링크를 올린 것을 감지한 뒤 4초쯤 후에 MacBook 쪽에서 연결을 엽니다. 잠자기에서 깬 뒤에도 같은 방식으로 붙습니다.

연결이 끊긴 뒤 계속 다시 시도하나요?

아니요. 4초·8초·10초 뒤 세 번만 자동으로 시도하고 멈춥니다. 그 뒤에는 iMac 쪽에서 연결하거나 메뉴의 지금 다시 연결을 누르세요. iMac이 깨어나면 스스로 연결해 옵니다.

트랙패드가 느려요

메뉴 → 설정 → 포인터 배율을 2×~3×로 올리세요. iMac 쪽 시스템 설정 → 마우스 → 이동 속도도 함께 조정합니다.

앱을 새로 설치했더니 권한을 다시 물어요

서명 인증서가 없는 빌드라 macOS가 버전마다 새 앱으로 봅니다. 손쉬운 사용·입력 모니터링을 다시 허용하면 됩니다.

iMac에서 새 키보드로 인식되지 않아요 (버전 업데이트 후)

iMac은 처음 페어링할 때 받은 키보드 구조를 기억합니다. iMac의 Bluetooth 설정에서 이 MacBook을 삭제하고 다시 페어링하세요.
